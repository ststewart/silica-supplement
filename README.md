# Supplemental Materials for 'Transitional Melt in Shock Front: Reinterpreting SiO₂ Shock Temperatures and the Melt Curve'


This GitHub repository contains supplemental material and replication data for:<br>

Amodeo, K. M., Davies, E. J., Spaulding, D. K., Millot, M., Stewart, S. T., Transitional Melt in Shock Front: Reinterpreting SiO₂ Shock Temperatures and the Melt Curve, submitted to <i>J. Geophysical Research: Solid Earth</i>, 2026.<p>

To run the Jupyter notebooks, build the conda environment:<p>

conda env create -f environment-silicapaper.yml<br>
conda activate silicapaper<p>

To rebuild the html Jupyterbook:<p>

jupyter-book build silica-book<p>

The output is in:<p>

silicabook/_build/html<p>
