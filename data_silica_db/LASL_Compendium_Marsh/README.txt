Data files for the shock wave data included in the out of print book:
Marsh, S.P., ed. LASL Shock Hugoniot Data. 1980, U. California Press: Berkeley

A fortran program is included to extract the data. This was
distributed by Mike Furnish at Sandia.

The hugla file is Marsh
The hugl3 file is van Theil

The references are from Scott Crockett. He does not have the van Thiel references.

The Marsh references appear in the files as shown in the below example
as “4  5  6” which is always three lines below the material
identifier.
